THE PLAN

Context engineering, instead of a trained LLM.

THE APPROACH
Each role is a distilled spec — a RoleProfile of target companies, title rules, and a weighted 7-dimension rubric.
It's injected straight into the prompt — no fine-tuning, no RAG, no embeddings. Just curated context.
The LLM scores 0–100 and tiers each candidate P0 / P1 / P2.
THE HONEST LIMITS → NEXT
The rubric weights are advisory, not enforced — scores can drift run to run.
Single model, single call — no voting, no eval set.
Next: force weighted scoring, and add a P0 spot-check eval to catch the drift.

THE PROBLEM

Proxy or direct?

A Proxy — InsightIQ
Proxy

Quick to build — InsightIQ already connects to the platforms, so we just call their API. But they sit between us and the data: we inherit their rate limits and pricing, and holding each creator's token ourselves gets hard.

B Direct — own the OAuth
Direct

More work upfront — we handle each platform's login ourselves. But then we own everything: the token, when it refreshes, and how we route each creator. For long-term monitoring, that control is what matters.

Monitoring (read-only, long-lived) → direct wins. Onboarding (write, cross-platform) → proxy may still win.
02 · Social
13 / 37
THE PLAN

Three things that broke.

PROBLEM
Sessions died on serverless
I kept each login in server memory — every Vercel cold start wiped it, logging users out at random.
FIX
Moved the session into an encrypted cookie (AES-256-GCM) — nothing to lose on a cold start.
PROBLEM
OAuth state broke
The login check kept a one-time token in a cookie — a blocked cookie or a second tab made it fail.
FIX
A signed token (HMAC) that carries its own proof — no cookie to lose.
PROBLEM
The errors lied
Instagram returned "Exception 100" — it reads like a bad request, but my code was fine.
FIX
The real cause was a missing Business Verification on Meta's side — found by checking the account, not the code.

THE PROBLEM

Coherence and drift.

The hard part isn't generating clips — it's keeping them coherent across scenes.
COHERENCE · SOLVED
A fixed story arc (hook → … → CTA) and a purpose on every scene keep the narrative from falling apart.
DRIFT · NARROWED, NOT SOLVED
The character and look still wander between clips. I narrowed it from four angles — a multimodal storyboard, brand keywords and palette in every prompt, an image anchor per clip, and a vision-QA loop that re-rolls clips that drift.
Narrowed — not solved. That's the honest state of the art here.

UI · DETAIL

A 4-line CSS fix.

THE PROBLEM
The Campaign-filter dropdown couldn't scroll when the list overflowed the viewport — and long campaign names rendered center-aligned after wrapping, collapsing the layout.
THE FIX · FOUR LINES
+ max-h-[60vh] overflow-y-auto
  → scroll once the list overflows
+ wrap name in <span class="flex-1 text-left break-words">
  → overrides the button's default text-align:center
+ gap-2 · shrink-0 on the check icon
Both hypotheses verified in Chrome DevTools before writing code. 4-line diff · zero business-logic impact · responsive across all screen sizes.

ENGINEERING PRINCIPLES

How I work.

Verify before code
Reproduce the bug and prove the fix — in DevTools, or a quick query against prod — before touching code.
Keep the change small
A 4-line bug gets a 4-line fix. Anything that writes to production waits for a sign-off.
Build reusable tools
Turn one-off analysis into scripts and READMEs the team can re-run — not throwaway work.
Security first
Tokens never reach the browser, sessions are encrypted, and secrets live in one central store.
Honest about limits
When a model hits its ceiling or a demo isn't adopted, I say so plainly — no spin.

WHAT I LEARNED

Where I grew.

— 01 / REPRO
Ask for a repro first
